# F2F Bank — тестовое задание Шипиловой Александры

End-to-end тесты на [Playwright](https://playwright.dev/) для F2F Bank — веб-приложения, имитирующего переводы между пользователями в стиле СБП (Vue.js фронтенд, FastAPI бэкенд, PostgreSQL).

## Стек

- Тесты: Playwright + TypeScript
- Приложение: Vue.js (клиент), FastAPI (бэкенд), PostgreSQL (БД), всё поднимается через Docker Compose

## Как запустить приложение

Понадобятся Docker Desktop, Docker Compose v2+ и Node.js 18+.

```bash
git clone <ссылка-на-репозиторий>
cd f2f-bank-tests
docker compose up -d --build
```

Приложение поднимется на **http://localhost**. Первая сборка занимает пару минут.

Остановить:
```bash
docker compose down
```

Полный сброс вместе с данными БД:
```bash
docker compose down -v
```

## Как запустить тесты

Приложение должно быть уже запущено:

```bash
npm install
npx playwright install chromium
npm test
```
Тесты создают собственных пользователей через API с уникальными email на каждый прогон, поэтому их можно гонять сколько угодно раз подряд без ручной очистки базы.

## Структура тестов

| Файл | Что покрывает | Тестов |
|------|----------------|--------|
| `tests/auth.spec.ts` | Регистрация, вход, защита маршрутов, сохранение сессии | 13 |
| `tests/transfer.spec.ts` | Переводы по номеру телефона: успешные, валидация телефона/суммы, недостаточный баланс | 10 |
| `tests/transactions.spec.ts` | Пополнение баланса, история транзакций | 5 |
| `tests/profile-and-navigation.spec.ts` | Профиль, навигация, логаут | 4 |
| `tests/known-issues.spec.ts` | Регрессионные тесты на все подтверждённые баги | 8 |

**Итого: 40 тестов, все проходят стабильно.**

## Сценарии и приоритеты

Перед написанием тестов я вручную иследовала приложение и проверила 47 сценариев после чего на этом этапе выявила 6 багов и некоторые замечания по UX, которые меня смутили.

Приоритет каждого сценария рассчитан по формуле `P = (IC × 4) + (TI × 3)`, где IC — влияние на клиентов, TI — техническое влияние (подробное описание методики и шкал выполнила в файле `NOTES.md`).
